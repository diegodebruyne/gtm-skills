# GTM Skills

Open-source Claude Code skills for outbound, GTM operations and campaign quality assurance.

## Skills

### Lemlist Check & Import

Runs 37 checks across lead quality, targeting, variables, Liquid rendering, sequence architecture, duplicates, blacklists, senders, deliverability settings and post-import verification before a Lemlist campaign can be launched.

See [skills/lemlist-check-and-import](skills/lemlist-check-and-import).

## Install a skill

Copy the desired skill folder into your Claude Code skills directory:

```text
~/.claude/skills/
```

Each skill contains its own installation and usage instructions.

## Security

Never commit API keys, `.env` files, lead exports, blacklists, campaign reports or client data. All bundled examples are fictional.
